# Mission: Build a fantasy real-time 4X game with MonoGame

## Why

Build `monogame-rt4x` from a working prototype into an independently maintainable full game, while gaining practical MonoGame game-development skill. The game should support fantasy empire building and real-time play rather than remain a tutorial exercise.

## Success looks like

- Build and run a MonoGame prototype from `monogame-rt4x` using Visual Studio or Visual Studio Code.
- Incrementally implement and understand the systems needed for a lo-fi fantasy RT4X game: terrain, time controls, UI, units, cities, diplomacy, AI, and pathfinding.
- Make informed architectural choices about 2D/3D presentation and underground-world representation before those choices become expensive to reverse.

## Constraints

- The learner has extensive C#/.NET experience and minimal MonoGame experience from a few completed tutorials.
- Use MonoGame 3.8.5+ with .NET 10 and the content builder project, not an MGCB config file.
- The learner performs subject-repository implementation; lessons and reference material stay in the teach repository.
- Visual style should be lo-fi: pixel art for 2D or low-poly for 3D.

## Out of scope

- Producing final art assets before core game systems work.
- Replacing traditional game AI with LLM-driven AI.
