Lesson 0002 · 20 minutes

Replace legacy MGCB with a Content Builder project

Your template currently uses the legacy Content.mgcb file and MonoGame.Content.Builder.Task. Convert now—before the top-down prototype acquires assets—so content rules live in reviewed C# alongside the game.

Model

Read the Content Builder project map. The game still loads from Content; a separate console project produces that folder during the build.

Your exercise

  1. From monogame-rt4x, create a sibling builder project and add it to the solution: 
    dotnet new mgcb -o FourxGame.ContentBuilder
dotnet sln monogame-rt4x.slnx add FourxGame.ContentBuilder/FourxGame.ContentBuilder.csproj
  2. In FourxGame.MonoGame/FourxGame.MonoGame.csproj, remove the MonoGame.Content.Builder.Task package reference. Keep MonoGame.Framework.DesktopGL.
  3. Before the final </Project>, add this MSBuild import: 
    <Import Project="..\FourxGame.ContentBuilder\BuildContent.targets" />
  4. Remove the legacy template artifacts: FourxGame.MonoGame/Content/ (including Content.mgcb and its generated bin directory) and FourxGame.MonoGame/.config/ (the legacy dotnet-tools.json location). Do not remove Content.RootDirectory = "Content" from Game1.
  5. Inspect FourxGame.ContentBuilder/Builder/Builder.cs. Leave its collection empty for now: there are no real assets to build yet. Its Assets/readme.txt merely marks the source-asset location.

Fast feedback

dotnet list FourxGame.MonoGame/FourxGame.MonoGame.csproj package
dotnet build monogame-rt4x.slnx
dotnet run --project FourxGame.MonoGame/FourxGame.MonoGame.csproj

The package list must not contain MonoGame.Content.Builder.Task. The build should then succeed with the builder project included, and the same cornflower-blue window should run. If it fails, paste the first error and your game .csproj; do not restore the legacy task as a workaround.

Retrieval check

Answer both prompts before opening the answer:

  1. Where do raw PNG files belong after this conversion?
  2. What does the BuildContent.targets import make the game build do?
Show answers

Raw PNG files belong in FourxGame.ContentBuilder/Assets/, then an explicit rule in Builder.cs selects them for processing. The import hooks content building into the game build and makes generated content available in the game output.
