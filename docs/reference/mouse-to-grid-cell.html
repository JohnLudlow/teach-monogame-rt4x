Mouse to grid cell

Use this when the player points at a screen-space grid and you need to know which cell is under the cursor.

mouseX = Mouse.GetState().X
mouseY = Mouse.GetState().Y

localX = mouseX - gridOriginX
localY = mouseY - gridOriginY

if localX < 0 or localY < 0:
  outside grid
else:
  column = localX / cellSize
  row = localY / cellSize
  inside only if column < columns and row < rows
Screen-space picking
Because the grid is currently drawn directly in window pixels, the mouse position can be converted to a grid cell with subtraction and integer division alone.
Grid origin
The top-left pixel where the grid begins. A margin or centering offset must be subtracted before dividing by cellSize.
Bounds check
A cell is valid only when its column and row both land inside the configured grid dimensions.
Update vs Draw
Mouse sampling and hovered-cell state belong in Update; the highlight rectangle belongs in Draw.

RT4X rule: first make pointing at a tile reliable. Selection, movement, and terrain rules can build on the same cell-mapping logic later.

Sources: MonoGame Mouse API, MonoGame MouseState API.
