Content Builder project map

FourxGame.ContentBuilder/
├── Assets/                 raw source assets
├── Builder/Builder.cs      rules: what to build or copy
└── BuildContent.targets    hooks builder output into the game build

FourxGame.MonoGame/
└── FourxGame.MonoGame.csproj
    └── Import ..\FourxGame.ContentBuilder\BuildContent.targets
Builder project
A separate console project that builds source assets into runtime content. It replaces legacy MGCB-editor configuration.
ContentCollection
The C# rules that select and process assets. Nothing is built by default: add explicit rules as asset categories appear.
BuildContent.targets
An MSBuild import in the game project that builds and copies content with the game.

Keep: Content.RootDirectory = "Content". The runtime content directory remains Content; the builder only changes how it is produced.

Source: MonoGame: Working with new Content Builder Projects.
