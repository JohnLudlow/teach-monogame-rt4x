The frame loop

MonoGame repeatedly calls two application-owned methods:

Update(GameTime gameTime)  // advance simulation
Draw(GameTime gameTime)    // render the current simulation state
Update
Read input, apply time-scaled simulation changes, decide game state. Do not draw here.
Draw
Clear the back buffer and render the state produced by Update. Do not make game decisions here.
GameTime.ElapsedGameTime
The elapsed real time since the preceding update. Use it to make movement and timers independent of frame rate.

RT4X rule: later, game speed scales simulation time in Update; it should not alter rendering cadence.

Source: MonoGame Game API.
