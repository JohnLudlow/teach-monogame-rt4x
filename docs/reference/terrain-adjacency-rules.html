Terrain adjacency rules

A compact contract for the first placement-rule slice: rule data is supplied to generation, every placed pair must be allowed, and a contradiction must not look like a finished map.

Rule contract

  • Enumerate eligible terrain types explicitly; exclude None and reject unknown types.
  • For an undirected cardinal edge, Allows(a, b) == Allows(b, a). Configure self-adjacency explicitly.
  • Replace the rule snapshot between generations to change placement rules; already generated maps remain unchanged.
  • A completed map satisfies Allows(map[x, y], map[x + 1, y]) for every horizontal edge and Allows(map[x, y], map[x, y + 1]) for every vertical edge.
  • No candidates means a contradiction for the current choices, not necessarily proof that no valid map exists.

Three different responses to a dead end

ResponseWhat it doesLimitation
Fail explicitlyReport seed and blocked cell; return no completed mapA valid arrangement might exist after different choices
BacktrackUndo a previous choice and try anotherNeeds saved decisions and a termination policy
PropagateRemove impossible candidates from neighbouring undecided cellsMay still reach a contradiction requiring failure or recovery

A fixed seed reproduces a choice sequence under the same generator and runtime; it cannot by itself guarantee a valid map. A greedy left/up filter is a stepping stone toward WFC's simple tiled model, not WFC itself.
