Screen-space grid recipe

Use this when you want a visible strategy map structure before you have real art assets or a camera system.

LoadContent:
  create 1x1 white Texture2D
  upload one white pixel with SetData

Draw:
  Begin SpriteBatch
  draw vertical lines as tall rectangles
  draw horizontal lines as wide rectangles
  End SpriteBatch
1x1 white texture
A single white pixel can be stretched into any line or filled rectangle because SpriteBatch.Draw scales the source texture into a destination rectangle and tints it at draw time.
Screen space
Coordinates measured in window pixels, not world coordinates. This keeps the first grid independent of scrolling and zoom.
Rectangle line
A grid line is just a very thin rectangle, such as 1 pixel wide by many pixels tall.
Update vs Draw
The grid's appearance is rendered in Draw; future map-state changes, cursor movement, and simulation decisions still belong in Update.

RT4X rule: build the first map as a stable visual scaffold. Add terrain, cursor logic, and time-driven simulation later, one layer at a time.

Sources: MonoGame SpriteBatch API, MonoGame Texture2D API.
