Question 1

In a 2D top-down game, which coordinate system would you use for each purpose?

  • Mouse cursor position
  • Unit position in the game world
  • Grid tile index
  • UI button placement
Show answers
  • Mouse cursor position: Input / Mouse coordinates (pixels from window top-left)
  • Unit position: World coordinates (game units from world origin)
  • Grid tile index: Grid coordinates (cell indices from grid origin)
  • UI button placement: Screen / Viewport coordinates (pixels from render target top-left)

Question 2

When converting from Screen to Grid coordinates, what is the correct order of operations?

  • Screen → Grid → World
  • Screen → World → Grid
  • Screen → Grid (direct division)
  • Screen → World (direct addition)
Show answer

Screen → World → Grid is correct. Screen coordinates must first be converted to world coordinates (applying camera transform), then to grid coordinates (dividing by cell size).

Question 3

For a camera that pans and zooms, what is the correct order for combining transform matrices?

  • Scale then Translate (zoom, then pan)
  • Translate then Scale (pan, then zoom)
  • Scale only
  • Translate only
Show answer

Scale then Translate is correct for camera transforms. If you translate first, the scaling will also scale the translation amount. Scaling first centers the zoom on the world origin.

Question 4

Why must you invert the camera transform when converting Screen to World coordinates?

  • Camera transform moves World → Screen
  • Camera transform moves Screen → World
  • Inversion is not required
  • Only for rotation transforms
Show answer

Camera transform moves World → Screen. The camera transform applies translation and scaling to convert world positions to screen positions. To go backwards (screen → world), you need the inverse transform.

Question 5

After converting screen coordinates to grid coordinates, why is bounds checking important?

  • Grid coordinates can be negative or exceed grid dimensions
  • Grid coordinates always fit in integers
  • Bounds checking is only for rendering
  • Grid coordinates are already validated
Show answer

Grid coordinates can be negative or exceed grid dimensions. Screen corners, especially with camera offsets, can map to locations outside the valid grid area. Always validate before accessing grid data.
